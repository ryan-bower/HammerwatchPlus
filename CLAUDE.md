# HammerwatchPlus: Claude entry point

Follow [AGENTS.md](AGENTS.md), the canonical safety, coordination, and evidence rules
for every agent. For GameLab work, read the [quickstart](gamelab/README.md),
[regression guide](docs/qa/REGRESSIONS.md), and detailed
[GameLab skill](.claude/skills/gamelab/SKILL.md). These files are committed and do not
depend on a machine-local playbook or a particular agent application.

README.md holds the current project status. Update both README.md and
`docs/RE_NOTES.md` at the end of every work session, as required by AGENTS.md.

## Where things are
- Game scripts: `gamecode/sdk/hoh2/scripts/` (AngelScript, regenerated by `tools/bootstrap.py`).
- Data: `gamecode/datatables/*.sval.json`, as parsed by the game.
- Mods: `mods/<id>/`. The id is the folder name. Mods are enabled per save via
  `gamelab/hps.py` (HashString = MurmurHash3_x86_32, seed `0xf808409c`).
- Mod module constructors run when the menu level (`levels/town.lvl`) loads.
  `UpdateFrame` ticks only after a session starts (`docs/RE_NOTES.md`, mod lifecycle).
- Log paths and the mod stack: `docs/MODDING_NOTES.md`. Hooks: `docs/hooks.md`.
- Mod conventions: `docs/modules.md`.
- Class planner (the class designs, Firearms included): `planner/`, run with `python -m planner`;
  records in `planner/data/<collection>/<id>.json` (`planner/README.md`).
- Run outputs: `gamelab/results/<time>-<scenario>-<mode>/`.
  See the regression guide for `run.json`, `inner.json`, `bot-results.jsonl`,
  telemetry, logs, screenshots, and source-epoch limits.
- Every gl verb, with its doc comment: `docs/generated/verbs.md`, generated by `tools/list_verbs.py`
  (`--check` fails when it is stale).
- Adding a probe: a `RegisterVerb` in `mods/gamelab-probe/scripts/GameLab/Probe.as`.
  Read-only, capped, reports truncation. Then a `{"do": "gl", "verb": ...}` scenario step,
  and re-run `tools/list_verbs.py`.
