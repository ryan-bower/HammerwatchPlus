# Firearms Specialist placeholder sprites, read by tools/generate/make_firearms_icons.py.
#
# One sprite per "== name" header, then its rows: one character per pixel, "." is
# transparent, every other letter is a palette colour (PALETTE in the tool). Rows may be
# shorter than the widest one (padded with "."). The tool adds the 1 px dark outline and
# the drop shadow itself, so draw only the object and its shading.
#
# Badges are the small symbols drawn in the bottom-right corner of an icon (bolt, flame,
# plus...). Icons are put together from these in ICONS in the tool, so a variant (the stun
# grenade, the magic missile) is a base sprite with a colour swap and a badge.
#
# For real art, draw the 24x24 icon in Aseprite / LibreSprite / Pixelorama and save it as
# art/firearms/override/<icon name>.png: an override always wins over the sprite here.
